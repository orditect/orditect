# Orditect

Recursive composite task governance for AI workflows — orchestration,
governance engine, streaming output plane, and storage contracts.

## Packages (planned, v0.1.0)

| PyPI | Role |
|---|---|
| orditect-core | Governance engine (Redis + Lua) |
| orditect-flow | Orchestration & recovery plane |
| orditect-stream | SSE streaming output plane |
| orditect-protocol | Storage contracts + conformance kit |
| orditect-adapter-memory | In-memory reference adapter |
